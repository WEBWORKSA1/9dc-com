# 9DC.com — Direct Current, Decoded

Free calculators and plain-English guides for the DC side of energy: EV fast charging, solar PV and batteries. Static Jekyll site for GitHub Pages (free plan).

- **9 tools:** fast-charge time, charging cost, road-trip stops, solar sizer, solar payback, battery bank, runtime, wire gauge, Ohm's law
- **Revenue:** Google AdSense (auto ads), lead-gen quote funnel, sponsorships, donations/memberships, contest sponsorship
- **Forms:** all routed through FormSubmit to a private inbox that is never written in the source. Submit any form once after deploy and click the activation email.
